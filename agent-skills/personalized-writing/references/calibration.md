# Keeping This Calibrated

This profile was built from a snapshot of writing. Voice drifts, and a static profile goes stale. Periodically — roughly quarterly, or whenever writing produced with this skill starts feeling off — feed 2-3 recent, unedited drafts back through voice analysis: sentence length distribution, paragraph openers, punctuation habits, recurring phrases, how transitions get handled. Update the rules above where the sample contradicts them, not the other way around. This file should track how you actually write, not calcify an old sample.
